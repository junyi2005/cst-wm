# CST-WM — project page

Project page for **CST-WM: A Causally Structured World Model for Embodied Visual Tracking**
by Junyi Hu, Shuaihang Yuan and Yi Fang (New York University Abu Dhabi).

**→ https://junyi2005.github.io/cst-wm/**

The page hosts the paper, the method overview, and the real-world deployment video.
This repository contains the project page only; no code or model weights are released here.
